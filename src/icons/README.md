# Lichess flip-board icon

`LichessFlipIcon.tsx` reproduces the `chasing-arrows` glyph (U+E020) from
[Lichess's icon font](https://github.com/lichess-org/lila/blob/master/public/font/lichess.sfd),
converted directly from the glyph outlines to an inline SVG. Lichess uses this
same glyph for [Flip board](https://github.com/lichess-org/lila/blob/master/ui/analyse/src/view/actionMenu.ts).

Credit: the Lichess authors and icon-font contributors. The font's attribution
and license information is in [Lichess COPYING.md](https://github.com/lichess-org/lila/blob/master/COPYING.md#exceptions-free).
